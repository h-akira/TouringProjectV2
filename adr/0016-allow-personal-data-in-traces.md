# 0016. Agent のトレースに質問・位置・回答が載ることは、いまは許容する

- 日付: 2026-10-30
- 状態: 採用

## 背景

Agent の Runtime は、OpenTelemetry の計装つきで起動する（AgentCore の既定）。Strands のトレーサーは、環境変数 `OTEL_SEMCONV_STABILITY_OPT_IN` に `gen_ai_unredacted_attributes=` が無いと、モデルへの入力（現在日時・緯度経度・町名までの住所・進行方位・質問の本文）、ツールの引数と結果、回答の文を、スパンのイベントにそのまま入れる。Agent と Backend は自分のログから質問と位置を除いているが、同じ内容がトレースの側で出ていく（全体レビュー R5-01）。

## 選択肢

1. 計装を切る（`agentcore.json` の runtime に `instrumentation.enableOtel = false`）
2. 計装は残し、環境変数で内容をすべて伏せる
3. 何もしない（トレースに載ることを許容する）

## 決定

3にする。利用者はプロジェクトの持ち主ひとりで、トレースを読めるのもアカウントの持ち主だけなので、質問・位置・回答が CloudWatch のトレースに残ることを問題にしない。トレースを他の人に見せる、または利用者が増えるときに、1か2で対応する（利用者の判断。2026-10-30）。

「質問と位置はログに出さない」という Agent と Backend のログの決まりは、手書きのログだけの決まりで、計装が出すトレースは対象外である。

## 影響

- Agent のログとトレースで、個人情報の扱いが違う。ログは伏せ、トレースは伏せない。
- Agent の `README` の「大事な決まり」に、この区別を1行書く（plan 6b）。
- 利用者を増やす前に、このADRを見直す。
